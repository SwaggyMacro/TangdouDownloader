### 🎯使用说明
1. 在视频链接输入框内粘贴需要下载的视频地址或者VID（一行一个，回车换行）
2. 选择清晰度（默认最高）
3. 点击“添加”按钮添加至下载列表
4. 点击“开始下载”按钮
5. 下载完成后视频自动保存至软件的运行目录
